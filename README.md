# Mistwood Frontier

Mistwood Frontier is a terminal‑style RPG built in Godot. Explore zones, battle enemies, manage pets, shop for gear, and uncover a growing world through text‑driven commands. Lightweight, fast, and inspired by classic MUD gameplay.

## Features
- Text‑based command system  
- Exploration across multiple rooms and zones  
- Combat with enemies  
- Player stats, leveling, and respawn system  
- Shops and inventory interactions  
- Pet system with combat companions  
- Save/load functionality  
- Retro terminal aesthetic

## How to Play
Download the latest release from the **Releases** tab.  
Run the executable:  MistwoodFrontier.exe


If the PCK is embedded, the EXE runs standalone.  
If not, keep the `.pck` file next to the EXE.

## Controls
Type commands directly into the terminal:
- `look` – inspect your surroundings  
- `move <direction>` – travel between rooms  
- `attack` – engage enemies  
- `shop` – interact with merchants  
- `pet` – manage your companion  
- `help` – view available commands  

## Development
This project is built using **Godot 4**.  
All source files are included except exported binaries.

To run the project:
1. Clone the repo  
2. Open the folder in Godot  
3. Run the main scene (`control.tscn`)
